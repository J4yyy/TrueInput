# True Input

**True Input** is a Spring Boot API that validates user inputs for correctness and format.  
Currently, the API supports validation of:

- **Email addresses**
    - Checks email format using regex.
    - Verifies host availability (but not mailbox existence).

## Features

- RESTful API built with Spring Boot.
- Lightweight and easy to integrate into existing systems.
- Provides clear responses on whether input values are valid.
- Extendable for additional validators in the future.
